# CorrLang has moved...

Hi and welcome to CorrLang!
Since the last time, quite a few things have changed (major refactorings, LLMs apppeared, ...).
In the midst of all these changes, the main development efforts also have been migrated to [Codeberg](https://codeberg.org/drstrudel/corrlang).
If you are looking for the most recent source code of CorrLang, please have a look there. 
This repository is now _archived_! 
What will remain on GitHub, is the [CorrLang CLI](https://github.com/webminz/corrlang-cli), please check it out.
